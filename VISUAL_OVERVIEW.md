## Animation Sequence

```
USER CLICKS TIER:
1. Card scale up (0.1s)
2. Checkmark pops in (0.6s)
   └─ Scale: 0 → 1.15 → 1
   └─ Rotate: -30° → target°
   └─ Opacity: 0 → 1
3. Glow pulse begins (infinite)
   └─ 2.4s loop
   └─ Brightness & shadow animation
4. Button text changes (0.2s)
   └─ "Select Plan" → "✓ Current Plan"
5. Card highlights (0.3s)
   └─ Border color intensifies
   └─ Background glow increases
```
