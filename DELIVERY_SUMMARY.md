## 🎨 Customization Guide

### Change Pricing
Edit `TIER_CONFIG` in BoostTierSelector.jsx:
```javascript
silver: { monthlyPrice: 1, yearlyPrice: 9, ... }
gold: { monthlyPrice: 2, yearlyPrice: 16, ... }
diamond: { monthlyPrice: 3, yearlyPrice: 27, ... }
```

### Change Colors
Edit `borderColor` and `glowColor`:
```javascript
silver: { borderColor: "#c7ced4", glowColor: "rgba(199, 206, 212, 0.4)" }
```

### Add/Remove Features
Edit the `features` array:
```javascript
features: [
  "Feature 1",
  "Feature 2",
  // Add your own
]
```
